1. Points to be Verified in Data Sheet

Check the Manufacturer part numbers configured in the latest data sheet.
Check whether actual dimension, recommended land pattern & symbol details are available in the datasheet.
Note: Ferrite components evaluation section on user (random) should be followed in case recommended land pattern is not available in the datasheet.
No assumption on the view from the drawing given in the datasheet.
Do we can follow mil (thousandth) if the dimension is provided in inches. All measurements should be checked with respect to datasheets.
Approval should be received before approving the below criteria components:
  • BGA: Less than 0.8mm Pitch.
  • QFN: Less than 0.5mm Pitch.
  • SON: Less than 0.5mm (Pitch/Width).
Not Recommended Murata Caps/Res, X2Y Capacitors, NORDIC IC & JST Custom Connectors are not recommended to use. (Approval should be provided by CTO or HW Tech).

2. Points to be Verified in Pad Stack

Padstack should be created by / Collected from Library Team Admin only. (Check in Central Library before creating Padstack to avoid duplication).
Footprint Pad should be defined as TOP or Internal Layer.
Do not disable the marked ticks inside the tool configuration:
Rectangle 10x19
Rectangle 10x20
Check the Through hole pad size (Square / Rectangle) utilizing the Pythagorean theorem to find Diagonal / Diameter.
a [ W ]
b [ H ]
c = √(a² + b²)
Example Setup:
Given: a = 0.5 mm, b = 0.7 mm
c = √[0.25 + 0.49] = 0.86 mm (Actual Diagonal)
Drill Size Calculation: (0.86 + 0.2) mm = 1.06 mm (41.7 - 42 mils)
Drill size to be increased 6 mils from the actual pin size. (For annular ring add 12 mils from the Actual AWG Dia). Drill size should be rounded up values (Ex: 41.47 → 42 mils, 46.22 → 46 mils).
Tolerance mapping value should be positive +/- 3 mils (Plated) / +3 mils (Non-Plated Hole Diameter (+/- 0 and Tolerance)).
Check the Pad stack naming. (Standard names already available in naming Padstack Standard - Central Library).
For Through hole components, a minimum annular ring of 10 mils is required on the top pad layer.
Verify the mask opening should be greater than pad size by 4 mils (2 mils per side).
Verify the mask-to-mask clearance should be 4 mils at least (If miniature component, maintained 4 mils – each 2 mils after approval).
Mask controlled mapping should be given for the pad which is connected to planes (Refer Datasheet) – Ex: GND, PWR & Center pad.
For SMD components, matching paired pads should be exactly identical in pad size.
Check paste stencil window size (Mylar / Stencil). For large pad sizes, segment the paste stencil space to 60 - 75% coverage using sub-divided blocks.
For Through hole components, pad mapping must be equal (Check standard rules if the component has variant sizing layouts inside the datasheet).
For Mounting holes, the board inner layer Anti-pad size must match the outer clearing size dimension.

3. Points to be Verified in Terms of Manufacturing

Check whether the Copper-to-Copper (Cu to Cu) clearance is maintained at a minimum of 6 mils for SMD components.
Check whether the Copper-to-Copper (Cu to Cu) clearance is maintained at a minimum of 10 mils for Through Hole Components.
Approval Required Obtain engineering sign-off for pad layout definitions on any BGA containing <0.65 mm Pitch.

4. Points to be Followed for Cell Creation

Points to be verified in Cell Editor
Cell Name should be mapped exactly as per standard library part reference land pattern availability guidelines.
Verify the orientation origin of the component. Landpattern should always be constructed from the Top View perspective.
Verify the pin name, pin number, and physical pin sequence map against the schematic symbol and component datasheet.
Cross-verify the exact X & Y coordinate locations of the pads relative to the designated cell origin point.
Always extract absolute pitch dimensions via "Pin Center to Center" metrics, discarding raw tolerance variables.
Verify Pitch, Row-to-Row space, Outer-to-Outer space, and Inner-to-Inner limits match recommended footprints.
Run physical simulation fitment checks matching target lead pins/through-holes against footprint layer structures.
Verify assembly drawing and placement outline clearance: Width = Nominal Width + Max(tolerance) [mils].
Verify Assembly Screen Text rules: (Height = 35 mils, Width = 35 mils & Line Width = 5 mils; Layer = assembly text).
Silkscreen reference designators / assembly part number fonts must be rendered in Verilog Font / Assembly Ref Des in Arial.
Verify the outer Placement Outline features a definitive line width dimension of 0.1016 mm / 4 mils.
Check both the assembly outline and silkscreen graphics to ensure a proper chamfer indicator designates Pin 1 placement.
Verify component dimensional data limits: absolute Width, absolute Length, and Maximum Height bounds inclusive of tolerance ranges.
Check component polarity markings where applicable (Ex: Diodes, LEDs, Polarized Capacitors).
Check long part overlays; verify if the physical layout needs restrictions to fit standard configurations.
Check the mounting hole types (NPTH / PTH). If unspecified, default to NPTH. Verify and confirm connector outer shell body composition.
Place clear routing keepouts (Router Obstruct) directly under ceramic bodies or metal case chassis to prevent under-component routing/vias.
Confirm contour properties are defined correctly (NPTH vs. PTH structural paths).
Collect mechanical parameters for module-level interfaces (Ex: QSFP cages): mapping mounting footprints, weight distribution rules, and thermal links.
For standard component via spaces and operational amplifiers: establish the three distinctive structural via class systems in the layout layers.
Enforce absolute maximum bounding envelope dimensions, including max tolerance ranges, for SIP Modules.
Provide a 0.5 mm rounded countersink clearance profile from maximum outer limits (with tolerance) on the opposite bottom layer.
For QFN Packages
Validate dimensions against IPC compliance standards.
Search central database for existing matching package definitions or compatible alternate layout footprints.
Generate fused configurations or direct recommended land pattern variations.
Produce Standard Recommended Footprints (Differentiate Defined vs. BMP footprint layouts for QFN families).
Enforce design restrictions over Center Pad Thermal Via arrays and spatial layout layer pad dimension mappings.
Apply strict mask-defined solder control boundaries if connected directly to critical copper zones like GND or PWR grids.
Integrate thermal via clusters per engineering documentation or adequate heat-sink vias for GSM, RF LNAs, Mixers, Power Amps, and Power Transistors.
For Leaded Packages (Ex: SOIC, TSSOP)
Validate footprints against target IPC standards.
Cross-check identical component frames or alternate layout options sharing identical physical shapes inside the main library.
Establish fused footprints or matching manufacturer-recommended patterns.
For Resistors / Caps (0201, 0402, 0603, 0805)
Validate footprints against target IPC standards.
Check matching component geometries or alternative packages with identical footprints inside the central library.
For BGA Packages
Ensure target pad land diameter maps to roughly ~80% of the true structural sphere ball diameter (Use existing reference definitions in central library).
Verify land details, corner pad breakdown geometry rules, and blind/buried micro-via breakout schemes.
Set solder mask opening structures per design specifications or datasheet guidelines.
Apply strict solder mask defined (SMD) pad rule controls over main system trunks like GSM and primary power connections.
Verify fiducial placement configuration maps around large BGA steps (Minimum of 3 alignment markers required).
For Connectors
Verify true mechanical mating length and width metrics. Set outer placement bounds matching worst-case maximum tolerance sizes.
Determine symmetric or asymmetric balance configurations with respect to origin points.
Provide note configurations indicating Pin 1 position if CON43170 & CON43171* are present. Map all explicit pin setups to standard design directives: DF-BP-CON-20279-002167.
Ensure explicit solder mask clearance windows encompass connector chassis shield grounding tabs.
Maintain connector shield boundaries at a minimum distance of 10 mils away from physical board outer edge lines.
Verify specific fiducial alignment mark placements relative to fine-pitch lead styles (Minimum of 3 markers required).
Verify all PCB landing pads conform to standardized profiles: strictly square, clean rectangle, or rounded oblong configurations.

5. Points to be Followed for Symbol Creation

Query central database for existing symbol mappings (Lookup via key attributes & Manufacturer; e.g., Power Limiter, Flash, Amplifier, Analog Devices, or Mini-Circuits).
Shape symbol pins per signal flow norms (INPUTS on Left, OUTPUTS on Right, POWER at Top, GROUND at Bottom). Note: Alternative functional mapping is allowed based on explicit application circuit layouts inside the datasheet.
Construct schematic symbols locked entirely onto a standardized 0.1 inch snap grid (Verify every pin center point snaps perfectly to grid).
Follow IEEE rules standard for pin naming conventions (Automatically populated by the manufacturer. Note: Pins should be alphanumeric populated based on bank details).
Render structural logic diagonal phase indicator symbols immediately forward of the functional pin line extension.
Audit logical designations: verify inversion bubbles, horizontal mirror layouts, and directional properties match standard reference models.
Following symbol generation, check that individual pin numbers display immediately adjacent to their respective pin name.
Assign symbol nomenclature parameters driven explicitly by the exact package configuration footprint code.
Crucial Process Extract pin names and numbers directly via digital clipboard from source text datasheets to avoid manual typing entry mistakes.
Map electrical pin property traits (Input, Output, Passive, Power) per operational source parameters.
Embed working hypertext documentation URL links directly inside the schematic component attribute syntax properties.
Verify database metadata properties (Part Description, Part Number, Part Name, and Type properties must be populated in the library editor).
Hide the primary base symbol model name within the editor display workspace (Center the default reference placement box inside the component body frame).
Ensure pin number notations orient horizontally in human-readable reading paths (If pin arrays reside on top/bottom edges, verify they maintain clear, un-flipped viewing paths).
When manipulating component graphic blocks, monitor the dynamic error report terminal log windows for system warnings (Duplicate Pin Name / Double Assigned Pin Number).
